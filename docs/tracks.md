considered for Grand Prizes." Sponsor prizes are opted into separately and do not count toward that
limit. Everything without the [HACKUMASS] tag is a sponsor prize.

## Rules, from the Devpost rules page (quoted)

- "You must submit a Devpost project here before Saturday at 11:59PM to be considered for judging.
  You can continue to edit and save up until the final hacking deadline of Sunday at 10AM."
  hackumass.com says the final deadline is 9:00 AM Sunday. Work to 9:00.
- "You must provide a public GitHub repository link in your submission under 'Try it out' links.
  Your code must remain public after the event to be eligible for prizes."
- "You must live demo your project in our judging space. Uploading a video demo for your project
  under 3 minutes is optional, but recommended."
- "We don't allow submitting a project that includes work done outside of the hacking period."
- "You can use libraries, frameworks, or open-source code in their projects. You must document any
  external code usages in your submission and mention during judging to clearly distinguish your
  contributions."
- "The max team size is 4 people. Each team member must have a Devpost account and be listed as a
  contributor on the project submission to be eligible for prizes."
- "Each team is only allowed to submit 1 project." And no submitting it to other hackathons.

There is no rule about AI coding tools on the rules page, and one MLH prize at this event
(SpaceXSI) is awarded for building with an AI coding agent. That supports Eddy's view that using
them needs no organizer question. The rule that does apply is the open-source one: external code
must be documented in the submission and mentioned during judging.

Schedule from hackumass.com: initial submission 12:00 AM Sunday; final 9:00 AM Sunday; judging
12:30 PM; deliberation 3:00 PM; closing ceremony 4:30 PM.

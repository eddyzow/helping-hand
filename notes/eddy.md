## Done and how it was tested

All of this is at the repo root, written before `newcontext.md` set the folder layout. None of the arm code has run on the real arm.

| File | What it does | Tested how |
|---|---|---|
| `see.py` | Takes a typed or spoken request and a camera frame, returns the pixel of the named object. Gemini does the hearing and the finding in one call. | Synthetic image with shapes at known positions: within 6 px. Refuses objects that are not there. A synthesized voice clip worked. Not tried with a real camera, real microphone or real photos. |
| `pick.py` | Request to grasp: pixel, to a position on a taught 3 by 3 grid, to hover, lower, close, lift, hand over. | Dry run on the synthetic image gives the right grid position and refuses out-of-reach objects. Grasp sequence ran against a simulated arm only. |
| `arm.py` | `teach` (grid of hand-posed poses), `pose` (one pose), `record` and `replay` (leader to follower). | Never run. Written from LeRobot's GitHub source: `lerobot.robots.so_follower.SO101Follower`, `get_observation`, `send_action`, `bus.disable_torque`. |
| `grid.py` | Blends taught poses so any point on the grid maps to joint angles. No inverse kinematics. | Self-check passes. |
| `draw.py` | Pen strokes from the Quick, Draw! database, from text (Hershey font), or generated by Gemini, with a preview image. `--go` traces them through a taught paper grid. | Previews look right for all three sources. `--go` never run. |

Model facts, measured Sat 12:10 AM on Eddy's free Gemini key: `gemini-3.5-flash-lite` answered every test correctly in about 1 second. `gemini-3.6-flash` worked on 3 of 4 at 3 to 4 seconds. `gemini-3.7-flash` and `gemini-3.8-flash` returned server errors. The robotics-ER models are not available on this key.
